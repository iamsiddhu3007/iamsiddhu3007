### 👨‍💻 About Me

I am a Software Engineer and Master of Science in Computer Science student at **Arizona State University** (graduating **May 2026**). My core expertise centers on **AI infrastructure, distributed systems, high-throughput backend services, and multi-agent platforms**. 

I thrive on bridging the gap between cutting-edge LLM capabilities and reliable, observable production systems — from designing multi-model routing meshes with circuit breakers and hybrid RAG pipelines to writing native macOS and cross-platform mobile apps.

- 🎓 **Education:** 
  - **M.S. in Computer Science** — Arizona State University *(Aug 2024 – May 2026)*
  - **B.Tech in Computer Science & Engineering** — Shiv Nadar University *(2020 – 2024)*
- 💼 **Teaching & Mentorship:** 
  - **Graduate Teaching Assistant / SCAI Grader** at ASU for **CSE 543** (*Information Assurance & Security*), **CSE 469** (*Computer & Network Forensics*), and **CSE 535** (*Mobile Computing*).
- 🏢 **Industry Experience:**
  - **Software Developer Intern** @ *Get SuperStars Inc.* — Spearheaded Flutter/Dart mobile architecture, reduced memory overhead by 80%, built 3-stage CI/CD pipelines.
  - **BTS Associate Intern** @ *ZS Associates* — Built 4-layer enterprise data warehouse schemas, end-to-end ETL for 70+ vendor feeds using Snowflake & Informatica IICS (Awarded **Dashing Debut Award** 🏆).
- 🌟 **Open Source:** Contributor to [**LiteLLM**](https://github.com/BerriAI/litellm) (PR [#25610](https://github.com/BerriAI/litellm/pull/25610) merged: pricing engine & routing specs for Gemini 3.1 Flash Lite Preview).
- 🎯 **Status:** Actively seeking **Full-Time Software Engineer** roles (AI Infrastructure / Distributed Systems / Backend / Full-Stack) starting **June 2026**.
